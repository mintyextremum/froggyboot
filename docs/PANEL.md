# Панель и управление классом

Панель: `http://<сервер>/panel/` (или `https://` при `HTTPS=yes`), пользователь `admin`.

## Классы и ПК

ПК описываются в `/etc/froggyboot/hosts.yml`:

```yaml
rooms:
  - name: "204"
    cols: 6
    hosts:
      - {name: room204-teacher, mac: 00-1a-2b-3c-4d-5e, row: 1, col: 1, danger: true}
      - {name: room204-pc01,    mac: 00-1a-2b-3c-4d-01, row: 2, col: 1}
```

- `name` — до 15 букв, цифр и `-`; показывается в меню, панели, журнале и становится именем компьютера в Windows.
- `row`, `col` — место на карте; без них ПК заполняют ряды по `cols`.
- `danger: true` — ПК допущен в опасную зону.

Изменения подхватываются без перезапуска. ПК, которых нет в файле, панель показывает в блоке «Незнакомые ПК» с готовыми строками для `hosts.yml`.

## Цвета на карте

| Цвет | Состояние за последние 3 часа |
| --- | --- |
| серый | нет данных |
| зелёный | загрузился с диска или установка завершена |
| жёлтый | в меню |
| оранжевый | в защищённой зоне или ждёт подтверждения |
| фиолетовый | назначена установка |
| синий | идёт установка |
| красный | ошибка установки |
| бирюзовый | прислал отчёт о железе |

Двойной клик по ПК — журнал и отчёт о железе.

## Назначение установки Windows

Выделить ПК → «Назначить установку Windows» → образ, редакция (список из `wimlib-imagex`), номер диска, копия `C:\Users`.

При следующей загрузке ПК показывает предупреждение на 15 секунд и ставит Windows без вопросов. Esc или «Cancel» — загрузка с диска. Назначение срабатывает один раз: после старта ПК снова получает обычное меню. Без загрузки назначение истекает через сутки.

Ход установки приходит из WinPE в `/srv/froggyboot/incoming/reports/<MAC>.log`: start, backup, partition, apply, drivers, bootloader, done или fail.

## Вход в защищённые зоны

| Логин | Пароль | Что происходит |
| --- | --- | --- |
| `tech` | пароль техника | зона Windows |
| `admin` | пароль администратора | зона Windows и опасная зона |
| `code` | код из панели | код действует до срока; после первого ввода — 15 минут и только на этом ПК |
| `ask` | любой | в панели и Telegram появляется запрос; после «Разрешить» ПК входит сам, доступ на 15 минут |

Коды из консоли: `froggyboot code windows --minutes 30`.

## Режим экзамена

Пункт из открытого раздела (например, live-система). В меню всех ПК остаются только загрузка с диска и этот пункт, он же выбирается по таймауту. Из консоли: `froggyboot exam tools/sysrescue`, выключение — `froggyboot exam off`.

## Wake-on-LAN

Кнопка в панели или `froggyboot wake room204-pc01`, `froggyboot wake 204` (весь кабинет). Пакет уходит на широковещательный адрес сети ПК, порт 9. WoL должен быть включён в BIOS.

## Отчёт о железе

Пункт «Hardware report» в утилитах: SystemRescue собирает производителя, модель, серийный номер, BIOS, CPU, память, диски, SMART и температуры, отправляет на сервер и выключает ПК. На диски ПК ничего не пишется.

## Telegram

В `config.env`: `TELEGRAM_TOKEN` (от @BotFather) и `TELEGRAM_CHAT` (id чата админов). Приходят: открытие защищённых зон, запросы `ask` с кнопками «Approve» и «Deny», начало и конец установки, отчёты о железе. Кнопки работают только в указанном чате.

## Консоль

```
froggyboot check | render | recipes | add <рецепт>...
froggyboot wake <имя|MAC|кабинет>...
froggyboot code <windows|danger> [--minutes N] [--mac MAC]
froggyboot exam <раздел/пункт|off>
froggyboot log [--mac MAC] [-n N]
```
