# Classroom placard / Табличка для класса

Print one version and hang it next to the PCs. The menu text itself is in English, because the iPXE console can't show Cyrillic.

Распечатайте одну из версий и повесьте рядом с ПК. Тексты в самом меню на английском: консоль iPXE не показывает кириллицу.

## ВНИМАНИЕ

Пункты меню с пометкой **[!]** полностью стирают диск компьютера, на котором вы их запускаете. Все файлы, программы и другие системы будут удалены без возможности восстановления.

Запускайте их, только если это ваш компьютер или у вас есть разрешение ответственного за класс. Перед установкой сохраните нужные данные.

Авторы сервера не несут ответственности за потерю данных. Все действия записываются в журнал: MAC-адрес, IP и время.

**Если ничего не нажимать, через 10 секунд компьютер загрузится как обычно.**
