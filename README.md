# Froggyboot

Меню сетевой загрузки для компьютерных классов на сервере с Debian. ПК загружается по PXE и получает меню: установщики Linux, live-системы, утилиты и установка Windows. Образы хранятся на сервере, классом управляют через веб-панель.

```
NETBOOT 192.168.1.10   room204-pc07   192.168.1.57   efi
 Safe
   [d] Boot from local disk  (default in 10 s)
   [l] Linux installers  >
   [t] Live systems and tools  >
 Erases disks - password required
   [!] Windows install  >
   [!] Danger zone  >
```

## Что умеет

**Загрузка**
- Работает рядом с чужим DHCP: dnsmasq в режиме proxy-DHCP, роутер не настраивается.
- Debian, Ubuntu, Fedora, Alpine, Arch, Mint, Memtest86+, GParted, SystemRescue, Clonezilla, ShredOS.
- Windows 10/11 через WinPE, BIOS и UEFI, с драйверами и `unattend.xml`; имя ПК из `hosts.yml`.
- Меню собирается из одного `menu.yml`; пункты без файлов скрыты.
- Образы скачиваются командой `froggyboot add <рецепт>` с проверкой SHA-256 по спискам дистрибутивов.

**Безопасность**
- Без нажатий через 10 секунд грузится локальный диск; если сервер недоступен — тоже.
- Пункты, стирающие диск: дисклеймер, пароль на сервере, ввод `ERASE`, выбор диска в WinPE.
- Вход паролем, одноразовым кодом из панели или запросом на подтверждение (панель, Telegram).
- Опасная зона: отдельный пароль и белый список MAC.
- HTTPS для паролей: свой центр сертификации, вшитый в iPXE.
- Журнал: время, IP, MAC, имя ПК, пользователь, действие.

**Управление классом**
- Карта классов в панели: кто в меню, кто загрузился с диска, где идёт установка, где ошибка.
- Назначение установки Windows на выбранные ПК: при следующей загрузке ставится сама.
- Отчёты WinPE по шагам установки, резервная копия `C:\Users` на сервер перед разметкой.
- Wake-on-LAN для одного ПК, выделенных или целого класса.
- Режим экзамена: в меню остаются только диск и один пункт.
- Отчёт о железе: модель, CPU, память, диски, SMART — на сервер, затем выключение.
- Уведомления и кнопки подтверждения в Telegram.

**Сервер**
- Debian 13, amd64 или arm64 (Raspberry Pi 5).
- Мастер настройки при первом запуске, пакет `.deb`.

## Как устроено

```
ПК ──PXE──> роутер (IP) + dnsmasq proxy-DHCP (имя загрузчика)
 └─TFTP─> iPXE ──HTTP(S)─> nginx ──> статические файлы: меню, ядра, WinPE
                             │
                             └──> приложение (127.0.0.1): меню под ПК, проверка
                                  паролей и кодов, журнал, панель, Telegram
 WinPE ──SMB──> Samba: install.wim и драйверы (чтение), отчёты и копии (запись)
```

Состав: dnsmasq, nginx, Samba, iPXE, wimboot, приложение на Python (FastAPI, SQLite). Если приложение остановлено, меню отдаётся статической копией, а защищённые зоны закрыты.

## Ограничения

- MAC-адрес подделывается; без `HTTPS=yes` пароль идёт открытым текстом. Защита от случайностей, не от атак в той же сети.
- Secure Boot: только экспериментальная схема с подписью своим ключом.
- Ubuntu и Mint грузят ISO в ОЗУ, нужно 8 ГБ.
- Нет многоадресной раздачи образов и бездисковых рабочих мест.
